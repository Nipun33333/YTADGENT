# Channel background music

`channel-bed.mp3` is an original 24-second ambient instrumental created for this
repository from synthesized tones. No third-party music, recordings, or audio
samples were used. You may use, modify, and redistribute it, including in
monetized videos, without attribution.

The mixer always selects this track, loops it for the video's duration, and
adds short fades. Its source level is approximately -18 LUFS; the default
music gain is 15% (-16.5 dB) so narration remains in front.
